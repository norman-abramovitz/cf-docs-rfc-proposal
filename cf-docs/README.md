# cf-docs index

Every document published on this site, in one list. The
[home page](../README.md) explains what the site is and where to start.

## Drafts

- [Requirements](../requirements/README.md): what the Docs WG is looking
  for in a new documentation stack, with requirement IDs.
  - [Audiences](../requirements/audiences.md): who changes the docs, who
    depends on them, and what each group needs.
  - [Keep and pain](../requirements/keep-and-pain.md): what works today
    and must survive the move, and what causes problems.
  - [Migration](../requirements/migration.md): the steps from today's docs
    to the new site.
  - [Research areas](../requirements/research-areas.md): open questions
    the requirements depend on.
- [Tooling](../tooling/README.md): the tools evaluated, their input
  formats, and the extensions each needs.
  - [Tools](../tooling/tools.md): each candidate tool and what was seen.
  - [Input formats](../tooling/formats.md): each format, with one real
    table written in it.
  - [What the PoC must cover](../tooling/poc-scope.md): what RFC #1642
    asks of its Phase 2 PoC.
- [Proof-of-concept results](../poc/README.md): what each tool built from
  real Cloud Foundry pages.
- [Glossary](../glossary.md)

## Side-by-side pages

- [Two outputs side by side](../poc/pair/index.html): any two versions of a
  test table, with the input for each.
- [Comparison](../poc/compare/index.html): the published table next to all
  four tools at once.
- [Tables, page by page](../poc/tables.md): each test page with its inputs
  and the differences found.
- [Table families](../poc/examples/index.html): the table families from
  the survey, with candidate styles.
