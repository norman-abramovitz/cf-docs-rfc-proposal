title: Partials round

Test pages from the partials round. passthrough: each partial included
with the template engine's `include`, in ERB delimiters, its content as
the earlier rounds' passthrough. native: the same include, with the
content in Markdown and the admonitions of the notes round; one shared
partial lives in `partials/shared/`. snippet: the native partials included with
`--8<--` (pymdownx.snippets). variable: a partial chosen by a variable.
probe: one partial with a heading, included twice.
