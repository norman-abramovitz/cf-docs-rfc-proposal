Log Cache allows viewing of logs and metrics over a specified period of time. The Log Cache includes API endpoints and a CLI plug-in to query and filter logs and metrics. To download the Log Cache CLI plug-in, see https://plugins.cloudfoundry.org/[Cloud Foundry Plug-ins]. The Log Cache API endpoints are available by default. For more information about using the Log Cache API, see https://github.com/cloudfoundry/log-cache-release/tree/main/src#apis[Log Cache] on GitHub.
