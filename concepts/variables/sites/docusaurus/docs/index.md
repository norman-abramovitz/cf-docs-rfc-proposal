slug: /
---

Test pages of the variables round, in two modes: passthrough (each
`<%= vars.name %>` written as `{vars.name}`, the book's values as they
are), and native (a variables module that holds every value in the form
MDX renders, and stops the build on a name it does not define). The raw
mode holds one page exactly as the book writes it.
