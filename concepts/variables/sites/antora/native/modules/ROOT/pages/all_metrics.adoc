= {app_runtime_abbr} Component Metrics

[[top]]This topic lists and describes the metrics available for Cloud Foundry system components. These metrics are streamed from the Loggregator Firehose. For more information about the Firehose, see link:../loggregator/architecture.html[Loggregator architecture].

The Cloud Foundry component metric names and descriptions listed in this topic may be out of date because Cloud Foundry component metrics change often. If you have questions about Cloud Foundry component metrics, consider contacting the component teams directly on their respective channels in the https://cloudfoundry.slack.com[Cloud Foundry Slack] organization. For example, you can contact the Diego team at *#diego*.
