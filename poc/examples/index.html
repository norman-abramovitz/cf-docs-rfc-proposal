Every kind of table in the Cloud Foundry docs, as published

The survey counted 241 tables in the docs and tutorial repos and sorted them into families by what they hold. Below are real examples of each family, screenshotted from docs.cloudfoundry.org at a 1280-pixel window. The last section shows four of them in each candidate style (standard, compact, striped, plain), so the styles can be judged on real content.

All 198 book tables look the same today: full width, cell borders, a shaded header, a row highlight on hover, no stripes. bosh.io (40 pipe tables) uses its own theme and is analyzed separately.

Candidate styles on real tables

Each candidate is a few lines of CSS added to the published page for the screenshot. They are mock-ups to compare looks, not the final rules, and they sit on the published site's theme, not on any of the four tools' themes.

compact  td, th { padding: 2px 6px; font-size: .85em; line-height: 1.3 }
striped  tbody tr:nth-child(even) td { background: #e9eef2 }   (borders kept)
plain    no cell borders; a rule under the header and a hairline between rows; header not shaded

What the screenshots show

  • Compact pays off on long tables: the 59-row metrics table goes from 7,639 to 4,781 pixels tall (−37%), the 21-row key-value table from 987 to 751 (−24%).
  • On the 12-column roles matrix, compact cuts the height by 27% but the table also narrows to fit its content (875 → 727 pixels), so the Activity column wraps to as many as seven lines. This table needs the key column kept wide (the existing key role and wrap: avoid hints) more than it needs less padding.
  • Striped adds little on top of cell borders, which already separate rows. It helps most on the wide matrix, where the eye follows a row across 12 columns.
  • Plain suits the media grid: the charts read as a grid of figures rather than as data cells. Compact makes no difference there, since the images set the size.
  • The two titled tables are the metadata tables already in the test pages; the title becomes a bold line above the table.
